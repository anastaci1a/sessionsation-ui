# Visual interaction reference

This directory describes the visual/input reference from
[cli-main-menu ae786af](https://github.com/anastaci1a/cli-main-menu/tree/ae786af695791fdf858eacf5780e04b5138be49d).
It is a source audit, not sessionsation-ui setup instructions or a claim that all
reference behavior is implemented. The Rust popup intentionally excludes the
reference's ASCII title and provider/lifecycle code. Its star field fills the PTY,
its entry is a HERDR popup, and new agents open in normal tabs.
